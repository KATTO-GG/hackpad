# hackpad
4-key macropad with rotary encoder, built for Hack Club's Hackpad program. :)
Features
4 mechanical switches (WASD-style layout, direct-wired to XIAO RP2040, no diode matrix)
Rotary encoder (volume up/down)
Seeed XIAO RP2040 as controller
Firmware: KMK (CircuitPython-based)
Case: 3D printed, [X]-part design (case + cover)
